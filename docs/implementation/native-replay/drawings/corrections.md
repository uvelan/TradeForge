## Independent review

The chart and toolbox consume the same pane-specific drawing list. Every anchor must resolve to an available candle on native replay. The underlying market-scoped book supplies the base for writes, including writes from panes that share a market. A rewind also cancels a draft whose existing anchors have become unavailable. The keyboard target retains a raw pixel row for arrow travel and a resolved anchor for preview and persistence. Enter checks candle membership again before committing the displayed anchor.
