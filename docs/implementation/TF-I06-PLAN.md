# TF-I06 implementation plan

Base and approved TF-I05 merge: fda26c7aff8d622c745b8c44d04b547f949defd4.

Reuse the structure stream observer, history reader, continuity rules and EventPage. Only confirmed BOS and explicitly enabled CHOCH may create a block. Countertrend and wick-only events are excluded. The most recent strictly opposing candle in the bounded accepted-bar lookback wins when its body and age pass and its availability is no later than the break. The search excludes the break candle and resets at any discontinuity, including a scheduled closure. Strictly ordered candle timestamps resolve ties. Break distance and optional same-direction break-body displacement are absolute price units. Wick or body geometry uses the actual source values and needs no symbol-derived tick rounding.

Evaluate existing zones before the current break. Only observations available strictly after formation can progress a block. Use first touch and monotone penetration under a wick or close rule, with full mitigation at the far edge. Gap-through with no overlap is invalidation, without inferred traded depth. Strict close beyond the far edge and missing open evidence also invalidate. Accepted-bar age expires first. Scheduled closures preserve existing zones. Corrupt archives are unavailable and old cursors are stale. There is no database migration.

Use domain-separated hashes for the candidate, local confirmed structure witness, zone and revision chain. Add an opt-in witness to the existing detector without changing existing structure IDs. Expose the raw confirming event and pivot IDs for the particular request alongside the stable witness and OB ID. Delivery limits and cutoff are excluded from event identity and the snapshot binds the full evidence sequence. Context links are informational and formation-availability constrained.

Bound candidate search and live state by policy. Use price and age indexes for lifecycle processing. Use existing caller and archive limits, benchmark both on identical inputs against FVG and report calculation, serialization, bytes and allocations. Reuse the chart primitive and scoped API response handling. Verify independent numerical fixtures, replay boundary, paging, archive integrity, rolling identity, source isolation, drawing gestures and both hosted workflows.

Review checkpoints: target P95 under 600 ms for 2,000 caller bars and 2.5 s for the 10,000-slot archive on this Windows test machine. These are benchmark budgets. Active zones and marker delivery are capped at 12 each per chart. Test exact cutoff and corruption before enabling the indicator in the library; the live book must be unchanged by zero-limit historical delivery. Context is opt-in and records only evidence available at formation. The implementation maintains the existing structure output for all call sites that do not request a local witness.
