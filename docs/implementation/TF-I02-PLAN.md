# TF-I02 implementation plan

Base a082ab7d9c74e2b8e50827c403227fc5a9ca8380 is merged PR #3. TF-I01 has an ordered OHLC validator, strict symmetric wick swings, a calculation registry, a closed-candle replay cutoff, and a bounded checksum-verifying historical reader. Existing session and SMT indicators use separate definitions. The chart can add indicator markers and reconcile series without replacing its primary chart or drawing controller.

## Rules

- Extract one bounded pivot primitive shared by the legacy swing path and the new version-1 structure definition. For each side, normalize tolerance in basis points of the pivot price. Strict requires every neighbor to be farther away in the correct direction. Earliest allows a right-side tie within tolerance, rejects left-side ties, and needs at least one materially different neighbor. Equal HH/HL classification compares consecutive confirmed prices on the same side with the pivot tolerance.
- Accept only closed evidence by cutoff. Process by availability then UTC candle time. Forward gaps clear active structure and the pivot window; a subsequently arriving older candle is flagged and does not backfill the already published event stream. This rule keeps the event stream prefix-stable. The minimum warm-up is left + right + one continuous candles.
- Bullish requires HH and HL. Bearish requires LH and LL. Mixed/equal evidence with enough pivots is neutral. Fewer than two pivots on either side is unconfirmed. A two-sided pivot is recorded on both sides and does not establish a direction on that candle. Established trend persists through continuation and pullbacks until a qualifying protected swing break or a gap.
- Evaluate breaks before registering same-candle pivot confirmations. The newest eligible unconsumed pivot is a break reference. This definition uses BOS for close through a level plus tolerance, and CHOCH for a close through the protected HL in bullish structure or LH in bearish structure. An opposing close through an unprotected swing reports a countertrend break and puts structure into neutral. After CHOCH, enter neutral and require fresh pivots on both sides before establishing another trend. An optional first wick cross emits a provisional event; a close confirms separately, and a later reclaim emits invalidation with no mutation of the earlier candidate. A consumed level cannot emit additional breaks.
- Fingerprint the accepted evidence prefix incrementally; derive event IDs from version, scope, parameters, event coordinates, and evidence hash. Keep top-level caller authority. The optional 10,000-slot server history path supplies one independently resolved series, never merges it with browser candles, and retains TF-I01 integrity limits. Archive checks and scheduled coverage authority remain distinct.

## Integration and verification

Use the same indicator library and persisted settings for calculations and separate swing/break/candidate toggles. Render markers and horizontal reference segments from backend events. Clear disabled/scope-stale output and cap visible markers to recent events. Validate exact independent fixtures for both trends and breaks, rewind and delayed evidence, ties and gaps, provenance and 2,000/10,000 bounds. Run complete backend and frontend suites and collect actual performance and replay screenshots before opening the PR.
