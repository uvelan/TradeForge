# Implementation roadmap

| Milestone | Tasks and dependency | Minimum viable acceptance gate |
|---|---|---|
| M0 — Correctness and evidence integrity | T01, T02, T03. Independent entry points. | Contradictory bid data produces untrusted outcomes, stale SMT alerts retract without altering history, replay never treats a forming bar as closed, corrupt duplicates fail, and temp-file/WAL recovery gate passes. Preserve early stops/targets and existing validations. |
| M1 — Market data and catalog reliability | T04 after T02/T03; T11 acquisition subset after T04. | Both APIs resolve a pinned range with identical legacy parity and manifest identities. Configurable storage cap and gap report. No default provider network or charges. Ready-to-restore snapshot. |
| M2 — Backtesting and execution fidelity | T06 then T07 after T01/T04. | Multi-partition replay equals a monolithic fixture, exact fixed-point behavioral results, first unknown coverage stops trusted metrics, conservative and declared fill assumptions, threshold/calendar policy versioned. Measure one-month memory/IO and disclose unresolved windows. |
| M3 — Indicator and strategy validation | T05 after T02/T04 and T10 after shared contracts. Start causal fixture harness before features. | M5 timing passes both engine and UI cutoffs. Two-worker restart and correction tests pass. Numerical goldens/warm-up and HTF closed-window tests pass. Add structure, liquidity and FVG before OB, independent CRT and confluence. |
| M4 — Trading UX and analytics | T08 after T04; T09 after versioned packages/metric lineage; T10 UI and T12 reporting only after their evidence gates. | Keep existing layouts, preferences and manual AI. Reconcile a redacted broker statement before verified financial metrics. Raw AI response and human decision auditable. Gap/coverage/alert status visible and chart performance within agreed workload. |
| M5 — Operational recovery and hardening | Complete T11; run T12 pilots only after upstream/benchmark gates. | Restore in clean Windows profile, forced termination/low-space drills, offline smoke tests, reproducible CI, no mixed histories. Scoped pilot rollback and package notices verified. |

T08 can begin in parallel after M1; real statement access gates release. T05 may land before M2 once evidence contract exists. M3 and M4 features release one at a time behind passing causal and data-ownership gates. Expected benefits are fewer misleading fills, stale signals, false duplicate successes and unsupported financial metrics. Speed, memory, analyst-time savings and framework alternatives require [measured workloads](06_TEST_AND_BENCHMARK_PLAN.md).
