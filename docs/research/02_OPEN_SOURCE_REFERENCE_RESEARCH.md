## Reuse and distribution posture

MIT/BSD/Apache source permits commercial use under its terms. Preserve applicable copyright/license notices and disclaimers in copied or redistributed artifacts. Apache distribution adds applicable NOTICE, modification marking and patent terms. GPL redistribution of a combined derivative can require corresponding source under GPL; apply ideas from the analysis behavior via independently written tests. LGPL permits commercial use subject to its terms; redistribution of library modifications and a combined work requires review of source, notices and ability to modify or replace/relink the library as applicable. A subprocess boundary helps preserve engineering isolation and is not an automatic licensing exception. TradeForge has no tracked root LICENSE at this revision. Decide outbound licensing before publishing borrowed code or packages. Separate all software obligations from vendor market-data rights. This is a source-license inventory, not legal clearance. [GNU license terms](https://www.gnu.org/licenses/) · [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)

For any pilot, pin exact hashes, verify Windows wheel/installer provenance and transitive licenses, run lock audit and dependency checks, disable live adapters/network in simulation, and test resource limits. No project-specific vulnerability clearance or third-party performance claim is made. The current TradeForge lock was checked for dependency consistency only.

## NautilusTrader

The Rust engine uses a virtual clock and dispatches multiple event types including quotes and bars. Simulated exchange processes instrument status and matching separately. The fill documentation distinguishes market/limit behavior, displayed size consumption and stochastic fills. Persist execution input, order intent, timestamps, trade/position/balance events, model/seed and deterministic exact fingerprints. Use typed instrument tick size/precision, explicit fee and latency, and immutable observations. Local event ordering and separate MT5 feed authority matter even with another engine. Source benchmarks are not TradeForge benchmarks. Review its data catalog as a batched-query reference, without adopting its Parquet schema as the local authority. ## LEAN

A tagged cash book and conversion service are a better model than a single unverified USD pip scalar. Preserve account currency, conversion direction, quote and available-at time, settled/unsettled cash as needed, explicit margin and brokerage specification and order events separate from fills. Its synchronizer provides a model for a frontier before strategy callbacks. Venue and security-specific fill rules matter; corporate actions are deferred for FX and if equities enter scope only. Leave LEAN integration out of the baseline. Equivalent accounting invariants are cheaper in Python than a .NET provider bridge, ZIP/history conversion, pricing/portfolio setup and native runtime maintenance. ## Freqtrade

Lookahead runs a baseline plus scoped signal reruns and compares indicators and shifted entries/exits. Recursive analysis changes startup history length, then compares the ending values. Borrow the independent checks with common UTC prefixes across both SMT instruments, and preserve order-type semantics when comparing fills. Add closed HTF joins and mutate the unseen suffix. For optimization use bounded walk-forward folds, immutable in/out-of-sample IDs, prespecified search budget and a report that discloses rejected/incomplete runs. No crypto broker or optimizer dependency. ## Dukascopy acquisition options

| Option | Feasibility and decision |
|---|---|
| Existing BI5 decoder | Keep as the canonical validated ingestion route. Expand manifest and completeness tests. Files are manually supplied; correctness of parsing does not imply data entitlement, source authenticity or no gaps. |
| Direct Python downloader | Preferred reference for a transparent authorized official S3 client. Reuse the decoder, make costs and credentials explicit, limit concurrency, treat each expected provider hour as a job, verify raw and decoded hashes. Do not add an AWS dependency until a small paid/authorized pilot is approved. |
| Isolated CLI | Conditional first automation pilot if endpoint rights permit it and raw artifact fidelity is established. Pinned npm package and argument list, no shell interpolation, private temp output, timeout/process-tree cancellation and bounded retries. Map each requested interval to a manifest state. Site terms restrict reuse and redistribution; confirm the terms for the exact S3/legacy endpoint, intended local archive, derived datasets and backup before automation. No live provider requests were made. ## Smart Money Concepts

The FVG uses the next candle and later scans mitigation. Centered swings use negative shift and later cleanup of consecutive extremes. BOS/CHOCH finds later wick/close breaks before assigning historical labels. Order-block mitigation and liquidity sweeps iterate across later candles. Session and prior highs/lows can be implemented causally via completed interval aggregates; verify boundary and timezone semantics independently. Use the definitions as visual references only. Record anchor, confirmation, first available, zone/wick reference, rule version, dataset, status and invalidation. Keep SMT and CRT independent. ## TA-Lib

Use as optional numerical oracle with explicit seeds, lookback, `float64` tolerances and input validity. Never convert missing data or gaps silently into numeric zero or invert the distinction between first output and convergence. [Function wrappers](https://github.com/TA-Lib/ta-lib-python/blob/c42d29c9862e5884f42bf92d2e5a98018a9839f0/talib/_func.pxi) · [Input tests](https://github.com/TA-Lib/ta-lib-python/blob/c42d29c9862e5884f42bf92d2e5a98018a9839f0/tests/test_func.py)

| Indicator | Comparison to implement |
|---|---|
| SMA / EMA | Rolling arithmetic mean should agree on contiguous data; EMA compare SMA seed and first output, and bound startup sensitivity on shared suffix. |
| ATR | TA-Lib lookback includes previous close; local first bar contributes high-low. Pin intended first output and convergence after a discontinuity. |
| RSI | Compare Wilder seeds, one-bar price-change offset, flat 50 versus default TA-Lib zero convention and monotonic sequences. |
| MACD | Force local slow/fast/9 mapping, examine seeding of both EMAs, jointly valid output versus local early MACD preview and signal warm-up. |
| ADX / Stochastic | Missing locally. Specify directional movement ties, zero range and double smoothing lookbacks for ADX, stochastic 0-range and fast/slow K/D for Stochastic. |
| Bollinger | Population deviation, basis SMA and 2 sigma, compare flat/large-offset inputs and floating precision. |

## Lightweight Charts

Use primitives textured only as needed for FVG/ob rectangles, session shade and risk/reward boxes, wick-to-wick SMT trendlines, price lines for levels, series markers for replay-visible position events. Price coordinate mapping must use the owning series and pane. Keep shared UTC timeline and crosshair conversions separate from display timezone. Use viewport clipping, stable identities, data updates on append and bounded annotations. The official primitive examples establish feasibility. Change framework only if profiling still fails under a realistic drawing budget. ## QuantStats

Consume explicit periodic, cash-flow-adjusted, account-currency returns from reconciled equity. Audit preprocessing and frequency, holidays, missing values, risk-free rate, sample minimums and units. Use locally verified trade records for expectancy and dollar profit factor; the library return-series profit factor is a different denominator and population. Drawdowns, rolling summaries, Sharpe/Sortino and reports are conditional enhancements. Keep working example data, manual journals and deterministic simulator metrics labeled separately.
