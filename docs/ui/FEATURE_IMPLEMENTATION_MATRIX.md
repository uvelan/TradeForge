# Feature implementation matrix

| Feature | Working scope | Open acceptance criteria |
|---|---|---|
| Signal Explorer | Cursor-paged SMT records, versioned archive and MT5 capture evidence, ID/source/time and linked-trade filters. | Separate transient-preview search. Other signal families require independently validated detection before indexing. |
| Evidence Inspector | Recorded timestamps, matching offsets, lineage, chart and alert marker navigation, both panes, user-captured PNG, exact related plan versions and copyable evidence. | Expanded marker and overlap coverage across browsers and panes. |
| Advanced replay | Immutable server-captured primary and comparison panes, visible-prefix evaluation, exact linked-SMT revision, UTC seeking, playback speeds and SQLite checkpoints/bookmarks. Saved simulation trades can jump to entry and exit candles. | Verify restart with real MT5 feed, delayed provider arrival metadata, and larger archived windows. |
| Data Trust | Terminal and library show feed/basis, exact selected archive lineage, UTC coverage calendar, truncation and gap details. Backtests reject contradictory quotes. | Provider-authoritative closure reasons, tick coverage calendar, active reconciliation and repair workflow. |
| Drawing toolbox | Native chart primitive with 17 tools, typed timestamp/price anchors, durable chart scopes and revision history, snapping, anchor edits, moving, styling, lock/visibility, duplication, undo/redo, and guarded deletion. | Freehand selection/hit tests for drawings and drag handles. Manual FVG, SMT and liquidity annotations are user marks. |
| Linked workspaces | Independent crosshair, range, zoom, instrument, timeframe and replay controls. Crosshair requires the receiving candle's exact UTC timestamp and displays missing candles explicitly. | Broader four-chart performance and gesture validation on real instruments. |
| Chart-to-plan | Select a chart's entry/stop/target, attach charts or recorded SMT evidence, draft autosave, two-step guided mode, audited version compare/append and no-trade decisions. | Broker-verified sizing and richer multi-step guidance. Calculations remain illustrative pending account/contract data. |
| Workspace presets | Save, rename, duplicate, delete, restore or reset validated display settings and import/export JSON. Search saved presets from the palette. | Drag-resizable custom panel configuration belongs to a later layout pass. |
| Command palette | Keyboard page and market commands, saved presets, registry indicators and bounded remote search for plans, signals, journals and datasets. Recent local commands and configurable palette chord. | Full keyboard registry remapping plus provider-specific instrument discovery in the palette. |
| Strategy results | Immutable hashed runs store actual candle inputs and parameters. Reload compares saved results, replays trades with historical windows, shows cumulative/drawdown R, outcome distribution, source lineage and verified quote-path pages. | Multi-partition tick execution, more strategies, broker-reconciled cash metrics and quote-cost detail beyond existing simulation data. |
| Master Journal | Searchable timeline, tags, signal/plan/PNG links, explicit append-only revisions and Markdown export. Stable IDs preserved. | Filters for other entity types and richer review/outcome navigation. |
| Session intelligence | Configurable same-day IANA windows and kill zones, as-of countdown, previous observed highs/lows, UTC day/week opens and chart shading. | Broker calendars and venue-specific daily/weekly opens beyond explicit UTC conventions. |
| Hardening | Windows build, backend, frontend and isolated browser suites plus version guards and additive SQLite changes. | Hosted Windows CI, full assistive-technology acceptance, crash/restore drill and representative soak/heap profiling. |
