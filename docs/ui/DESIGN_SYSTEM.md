# Design system

The research screens reuse Card, Notice, Select, small-tool and the existing workspace shell. The signal list and inspector share a responsive grid, wrapping controls, focused keyboard outlines, and status text that does not depend on color. Evidence identifiers wrap within a narrow panel. The native command dialog has keyboard focus management and Escape close. Existing chart colors and timezone preferences remain in the same hooks. The implementation does not add a theme library.

The full token consolidation, resizeable drawers, and all-viewport accessibility checks remain open.
