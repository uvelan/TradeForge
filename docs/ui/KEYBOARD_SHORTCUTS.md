# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| Ctrl+K by default | Open command palette. Settings offers Ctrl+Shift+K and Alt+K as alternatives. |
| Up / Down, Enter | Select and invoke matching commands. |
| Escape | Close native dialog or leave chart drawing. |
| Space | Play or pause an active replay outside interactive controls. |
| Shift+Left / Shift+Right | Step replay backward or forward. |
| Alt+H | Toggle the existing horizontal level tool in Market Terminal. |

Use the toolbox buttons for undo and redo. Keyboard shortcuts avoid active inputs and page dialogs. Other shortcut remapping remains open.
