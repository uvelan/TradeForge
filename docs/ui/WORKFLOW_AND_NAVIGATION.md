# Workflow and navigation

Find a saved SMT event in Signal Explorer, inspect the confirmed pivots and exact lifecycle, and open the chart or replay. Save a replay position to resume the same capture. Use Save chart evidence for a user-captured PNG and attach it to a plan or lesson. Signal marker and alert clicks can open their recorded revisions. Related plans link to exact saved versions.

The planner starts with known context, leaving trigger and unknown prices for the user. Select prices on the chart or enter them manually. Drafts are browser-local, while published versions use guarded SQLite writes. The planner can compare versions, append a revision, record an outcome or record a no-trade decision. AI packages can include the selected signal and chart capture. Journal entries can link to that signal, that plan version and the chart and preserve the old entry when a revision is appended.

Strategy Lab saves completed run requests and input candles. Select a stored run to compare summaries or inspect a specific trade and its original quote sequence. Use the command palette for pages, named instruments, indicator registry, presets and a paginated record search.
