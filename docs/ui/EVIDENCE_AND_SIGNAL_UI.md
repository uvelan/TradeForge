# Evidence and signals

Signal Explorer returns the latest transition per stable verified event key. Corrections take precedence over ordinary invalidation, confirmation and candidates. An invalidated or corrected event can retain its historical confirmation time and remains available for review. Neither state appears in the active alerts endpoint.

The inspector separates pivot position from actionability time, shows actual pivot offsets and feed lineage, verifies the stored candle capture, and can seek within both charts. Signal markers, alert evidence and journal entries can open a corresponding recorded revision. Linked plans list exact versions. Chart images created by the user retain their own capture provenance and can be selected for a plan or journal entry without altering the source capture.

Transient client previews remain in the chart. New signal families require their own causal detectors and fixtures.
